# Roomus Website

## Overview
The Roomus website is designed to showcase the services and information related to Roomus. It is built with a focus on user experience and aesthetic appeal, utilizing a moodboard and style tile for design references.


## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to view the website.
3. Modify the CSS and JavaScript files as needed to customize the website.

## Features
- Responsive design that adapts to various screen sizes.
- Interactive elements powered by JavaScript.
- Clean and modern aesthetic based on the provided design references.
